## ⚠️ Important Rules

* **File Name Must Be Exact:** The display system looks specifically for a file named `index.html` (all lowercase, no spaces).
* **Don't Forget the Yodeck Step:** Saving here updates the website, but the physical screens often cache old versions until restarted.

---

## Method A: Edit the File Directly in GitHub (Recommended)

This is the fastest method—no need to download or rename files on your computer.

1. Open this repository on GitHub.
2. Click on the **`index.html`** file in the list.
3. In the top-right corner of the file preview, click the **pencil icon** (✏️) to edit.
4. Select all existing text inside the editor (`Ctrl + A` on Windows or `Cmd + A` on Mac) and delete it.
5. **Paste** the entire new code provided by your AI.
6. Click the green **"Commit changes..."** button at the top right.
7. Leave the default options selected and click **"Commit changes"** to save.

---

## Method B: Upload a New File

Use this method if the AI gave you a downloaded file (e.g., `generated_code.html` or `output.html`).

1. **Rename the file on your computer first:**
   * Right-click the downloaded file.
   * Rename it to **`index.html`** (ensure `.html` is at the end and everything is lowercase).
2. Go to the main page of this GitHub repository.
3. Click the **Add file** button near the top right and choose **Upload files**.
4. Drag and drop your newly renamed `index.html` file into the box (or click "choose your files").
5. Scroll to the bottom and click the green **"Commit changes"** button.

## 📺 Updating the Physical Screen (Yodeck)

Once you have saved your changes to GitHub, an action will push it to Yodeck and push to screen.

If it doesn't automatically do this, you'll have to log in to the dashboard and reload that player:

1. Check that the updates look correct by visiting **[ssmbauckland.github.io/announcements-tv](https://ssmbauckland.github.io/announcements-tv/)** on your computer or phone.
2. If the physical display screen does not update automatically within a few minutes, **restart the Yodeck media player** connected to the TV/monitor:
   * **Via Yodeck Dashboard:**
   * <img width="550" height="801" alt="image" src="https://github.com/user-attachments/assets/af2c77b5-49ca-43f2-a546-2135cda1d927" />
   * **Manually:** Unplug the power cable from the small Yodeck player box behind the TV, wait **10 seconds**, and plug it back in.

### Need Help?
If the screen shows a blank page or an error, check that the file is named exactly `index.html` and that the full code from the AI was pasted without missing parts.
